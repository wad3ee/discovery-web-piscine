# Discovery Web Piscine

## Introduction

This project makes me more comfortable using the terminal and Linux commands. It is my first time using Git and GitHub. I learned how to manage my files and keep track of my changes.

## Why Git Makes Development Easier

Git makes development easier because it keeps track of changes in a project. If I make a mistake, I can use the Git history to understand what changed and return to an earlier version when needed. Git also makes collaboration easier because developers can work on the same project and share their changes. GitHub allows me to store and share my Git repository online.

## What I Learned

I learned how to use Linux commands such as `pwd`, `ls`, `cd`, `mkdir`, and `touch`. I also learned how to use Git and GitHub to manage my project. I learned how to initialize a repository with `git init`, stage files with `git add`, save changes with `git commit`, and upload my work to GitHub with `git push`.

## Git Workflow

My Git workflow is simple. First, I create or modify files in my project. Then I use `git add` to stage the changes. After that, I use `git commit` to save the changes in Git history. Finally, I use `git push` to upload the changes to GitHub.
